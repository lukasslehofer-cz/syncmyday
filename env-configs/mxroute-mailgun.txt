# ============================================
# INSTRUKCE
# ============================================
# 1. Zkopíruj tyto řádky do svého .env souboru
# 2. Nahraď všechny hodnoty (kromě hostů a portů)
# 3. MXroute heslo: z DirectAdmin → Email Accounts
# 4. Mailgun SMTP heslo: z Dashboard → Domain → SMTP credentials
# 5. Mailgun API klíč: z Dashboard → Settings → API Keys
# 6. Mailgun Webhook klíč: z Dashboard → Settings → Webhooks
# 7. Po změně spusť: php artisan config:clear

# ============================================
# CO KDE ZÍSKAT
# ============================================
# MXroute SMTP credentials:
#   → DirectAdmin → Email Accounts → klikni na email
#
# Mailgun SMTP credentials:
#   → Dashboard → Sending Domains → klikni na doménu → SMTP credentials
#
# Mailgun API key:
#   → Dashboard → Settings → API Keys → Create New Key
#
# Mailgun Webhook Signing Key:
#   → Dashboard → Settings → Webhooks → Webhook Signing Key
#
# Mailgun Inbound Routes:
#   → Dashboard → Receiving → Routes → Create Route
#   → Expression: events@syncmyday.cz
#   → Action: https://syncmyday.cz/api/webhook/mailgun-inbound
